# Agent 0.1.3 验证记录

2026-10-06，Windows x64，Node.js 24.19.0 构建。仅修改 Agent 和文档，后端与前端无需为此重新部署。

## 行为与边界

- 跟随 Windows 默认音频输出并使用共享模式，观察音频设备列表和输出驱动；记录 mpv 原生报错与退出码。
- 意外退出时暂时报告播放器未就绪，已开始的歌曲保留任务身份并从已校验的本机缓存恢复位置、暂停状态和音量。启动失败仍重试；10 秒内连续退出或恢复加载超时会结束当前任务，避免无限重播。普通文件解码错误不尝试重播。
- 停止指令在恢复期间仍可下发。每一步恢复都检查任务身份、制动代次、播放器实例和连接租约；制动后解除也不能继续旧恢复任务。恢复未结束时不提前接收下一首。
- 本机控制接口接受 0–86400 的整数秒；播放器按实际文件时长限制到末尾前一秒，使用 `seek absolute+exact`，不修改暂停状态。非整数、负数、旧任务、制动和未就绪状态拒绝跳转。
- 桌面进度条和输入框按 1 秒调整，拖动完成后提交；输入期间不被状态轮询覆盖。总时长优先使用 mpv 实际读出的数值。
- 新增状态仅通过本机 IPC 传递，不新增远程协议指令。原后端继续支持播放。

## 验证

`npm test`：5 个文件、15 个用例通过，覆盖退出重启、恢复位置、连续崩溃、恢复期间停止/制动/租约过期、整数秒跳转、暂停保持、过期和错误任务拒绝、本机认证、日志脱敏与下载校验。

`npm run package:win`：构建独立 exe，附带内置 mpv、NSSM、桌面控制台、许可证与 SHA-256 校验和，不包含真实设备配置。

`npm run test:package`：临时后端与真实打包 exe/内置 mpv 联调，测试静音 WAV。确认四路下载与校验、暂停/继续/音量/停止、17→18→17 秒跳转、WASAPI 重新初始化、终止测试专属 mpv 后保留原任务及暂停位置恢复，以及桌面真实跳转/制动按钮、持久化锁和手动解除。安装参数与回滚采用模拟验证，不由该测试安装系统服务。

桌面界面通过 WinForms 渲染检查，无控件重叠。测试创建的目录、日志和预览图在完成后清理。


声卡、扬声器和耳机的物理切换需要在目标电脑验证。自动化测试只对测试专属播放器执行输出重初始化和进程恢复。
